# `paper/` — the SO(3,3) preprint

`main.tex` is the preprint source; the content is complete and only the
mechanical submission steps (below) are open.

## Layout

- `main.tex` — the paper (stock `article` class; builds with any TeX Live).
  The `[SUBMIT]` markers in the preamble flag what to swap when moving to a
  conference style.
- `refs.bib` — bibliography. arXiv ids sit in `eprint` fields. Titles,
  authors and ids were written from memory and are **not yet verified** against
  the arXiv/journal records (see the header of the file).
- `figures/` — `equivariance_vs_norm.pdf` (Figure 1) and its data
  (`equivariance_data.csv`), generated by `python -m benchmarks.figure_equivariance`.
- `runs/week1.sh` — shell pipeline for every multi-seed experiment in the paper
  (boost-OOD, HIGGS, Adult, top tagging internal and canonical). Appendix B of the
  paper has the same commands.
- `notes/` — working notes behind the paper: `diagnosis_findings.md`,
  `equivariant_diagnosis.md`, `top_tagging_finding.md`, `results_week1.md`,
  `related_work.md`. `notes/archive/` holds superseded material
  (an old benchmark report and an early results table) kept for history only.

## Build

```bash
cd paper/
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

After the first `bibtex main`, look at `main.blg`: it should report no errors.

## Reproducing the numbers

Per-seed JSON records go to `results/` (git-ignored); the tables are rebuilt with

```bash
python -m benchmarks.aggregate --out paper_tables.md
```

Top tagging has two protocols, both in §4.5: a controlled 100k-jet ablation on an
internal 70/15/15 split, and the canonical Kasieczka protocol
(`--canonical-splits`, full published 404k test set). The canonical tables report
background rejection 1/ε_B at ε_S = 0.3 next to AUC. The published rows in
Table `tab:topt-canonical` are quoted from the literature, not re-run.
